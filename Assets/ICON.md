# Icona iPhone Remote

Icona creata con il tool integrato **ImageGen**, senza CLI o chiave API. Originale: `AppIcon-source.png`. Variante finale: `AppIcon-final.png`. Risorsa macOS: `AppIcon.icns`. `Scripts/build-icon.sh` crea le rappresentazioni di risoluzione necessarie e il contenitore ICNS con gli strumenti di sistema.

Prompt iniziale:

> Use case: logo-brand. Asset type: macOS application icon for a personal native app named iPhone Remote. Create a single polished app icon: a precise silver smartphone silhouette paired with a simple mouse pointer, clearly communicating control of an iPhone from a Mac. A dimensional rounded-square tile, restrained graphite and silver with a subtle cool luminous accent, clean native macOS visual character. Centered, highly legible at Dock sizes. No text, letters, trademarks, Apple logo, surrounding scene, or mockup. Square composition, transparent background outside the rounded tile with a modest consistent margin. Deliver a finished bitmap icon, not a presentation sheet.

Prompt della variante finale:

> Edit only the transparent exterior of this macOS icon. Remove the stray white/blue speckles and artifacts above and outside the rounded-square tile, leaving that exterior clean and fully transparent. Preserve the tile, smartphone, pointer, blue rings, colors, composition and dimensions exactly. No other changes.
